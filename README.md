# RepeatedTasks

Консольный трекер времени, прошедшего с последнего выполнения задач.

**Это не планировщик.** У задач нет расписания, периодичности и напоминаний —
и это намеренно. Приложение отвечает на один вопрос: *когда я делал это в последний
раз и сколько с тех пор прошло?* Вы сами решаете, пора ли; программа лишь честно
показывает, сколько времени утекло.

Подходит для дел, у которых нет твёрдого срока, но которые неприятно запускать:
полить цветы, поменять фильтр, сделать резервную копию, проверить огнетушитель.

---

## Возможности

- **Дерево задач** с подзадачами любой вложенности, ветки сворачиваются
- **Время с последнего выполнения** у каждой задачи — главный показатель
- **История выполнений**: все отметки, интервалы между ними и статистика
- **Две канбан-доски** — по сложности и по срочности
- **Автосохранение при выходе**, данные переживают закрытие приложения

## Как выглядит

Главное меню:

```
+========================================+
|          R e p e a t e d T a s k s     |
+========================================+
|  1. Список задач (дерево)              |
|  2. Добавить корневую задачу           |
|  3. Канбан-доска: СЛОЖНОСТЬ            |
|  4. Канбан-доска: СРОЧНОСТЬ            |
|  5. Сохранить на диск                  |
|  6. Перезагрузить с диска              |
|  0. Выход (с сохранением)              |
+========================================+
Корневых задач: 4
```

Список задач. В квадратных скобках — сколько прошло с последнего выполнения,
`C:` — сложность, `Cr:` — срочность. Маркер `[-]` у развёрнутой ветки,
`[+]` у свёрнутой, `[ ]` у задачи без подзадач:

```
========== СПИСОК ЗАДАЧ ==========
[-] 1. Обслуживание квартиры  [никогда]  C:Средняя  Cr:Низкая
  [ ] 2. Полить цветы  [2д 3ч]  C:Низкая  Cr:Высокая
  [ ] 3. Поменять фильтр воды  [3м 5д 0ч]  C:Высокая  Cr:Средняя
[ ] 4. Резервная копия ноутбука  [11д 0ч]  C:Высокая  Cr:Высокая
[ ] 5. Проверить огнетушитель  [1г 2м 5д 0ч]  C:Средняя  Cr:Средняя
[ ] 6. Разобрать архив фотографий  [никогда]  C:Высокая  Cr:Низкая

Введите номер задачи для открытия,
или -N чтобы свернуть/развернуть ветку, 0-назад:
```

Карточка задачи:

```
========== ЗАДАЧА ==========
Название:      Полить цветы
Описание:      -
Послед.выполн: 2д 3ч назад
Выполнено раз: 4   (обычно раз в 5д 15ч)
Не позже:      -
Сложность:     Низкая
Срочность:     Высокая
Подзадач:      0

1. Отметить выполненной (сбросить счётчик)
2. Добавить подзадачу
3. Редактировать
4. Удалить эту задачу
5. История выполнений
0. Назад
```

История выполнений — видно не только «когда последний раз», но и насколько
регулярно задача выполнялась на самом деле:

```
========== ИСТОРИЯ ВЫПОЛНЕНИЙ ==========
Задача: Полить цветы

Всего выполнений: 4
Обычный интервал: 5д 15ч   (от 5д 0ч до 6д 21ч)
Прошло с последнего: 2д 3ч

  №  Когда                  Прошло с предыдущего
  -------------------------------------------------
  4  20.09.2026 04:07       6д 21ч
  3  13.09.2026 07:07       5д 0ч
  2  08.09.2026 07:07       5д 0ч
  1  03.09.2026 07:07       -

1. Добавить прошлое выполнение
2. Удалить ошибочную отметку
0. Назад
```

«Обычно раз в 5д 15ч» — это описание того, что происходило, а не заданное
расписание. Просроченных задач в программе не бывает.

Канбан-доска:

```
+------------------------+------------------------+------------------------+
|              К А Н Б А Н   Д О С К А   (С Р О Ч Н О С Т Ь)               |
+------------------------+------------------------+------------------------+
| ВЫСОКАЯ                | СРЕДНЯЯ                | НИЗКАЯ                 |
+------------------------+------------------------+------------------------+
| Полить цветы [2д 3ч]   | Поменять фильтр воды [ | Обслуживание квартиры  |
| Резервная копия ноутбу | Проверить огнетушитель | Разобрать архив фотогр |
+------------------------+------------------------+------------------------+
```

## Сборка

Весь проект — **один файл на C++98** без внешних зависимостей и
платформенно-зависимых вызовов.

### C4Droid (Android, основная платформа)

Откройте `DP_Repeated_Tasks.cpp` в C4Droid и соберите как консольное приложение
либо экспортируйте в APK. Никакой настройки не требуется: ни сторонних библиотек,
ни `Makefile`, ни флагов компилятора.

### Настольная сборка

```sh
g++ -std=c++98 -Wall -Wextra -O2 -o repeated_tasks DP_Repeated_Tasks.cpp
./repeated_tasks
```

Собирается любым GCC или Clang. Единственное отступление от стандарта — `long long`
для 64-битных меток времени; это расширение поддерживают все распространённые
компиляторы. В остальном код строго C++98, поэтому годится и для старых тулчейнов.

Терминал должен уметь UTF-8 — интерфейс на русском.

## Хранение данных

Всё лежит в `repeated_tasks.dat` **рядом с рабочим каталогом программы**.
В C4Droid это внутреннее хранилище приложения, отдельной настройки не нужно.

> Путь относительный, поэтому при запуске из другого каталога программа не найдёт
> прежние задачи и заведёт новую базу. Запускайте её всегда из одного места.

Сохранение устроено так, чтобы данные нельзя было потерять:

- запись идёт во временный файл и лишь затем атомарно подменяет рабочий,
  так что оборванная запись (закрытие приложения, нехватка места) не повреждает базу;
- предыдущая версия остаётся в `repeated_tasks.dat.bak`;
- ошибка записи не остаётся незамеченной — программа сообщает о ней, а не рапортует
  об успехе;
- повреждённый файл не затирает то, что уже загружено: программа отказывается
  его принять и объясняет, что именно не так.

Формат текстовый и построчный, заголовок — `RTASKS3`. Файлы всех прежних версий
читаются и переписываются в новый формат при первом сохранении.

Ограничения (защита от повреждённого файла): до 50 000 задач, вложенность до 64
уровней, до 10 000 подзадач у одной задачи, до 5000 отметок о выполнении на задачу,
метки времени в пределах 1970–2100.

## Как пользоваться

1. **Заведите задачу** — пункт 2 главного меню. Если её уже делали раньше,
   при создании можно указать, когда именно.
2. **Сделали дело — отметьте**: пункт 1 в карточке задачи. Счётчик обнулится,
   а в историю добавится запись.
3. **Забыли отметить вовремя** — не беда: в истории есть «Добавить прошлое
   выполнение», запись встанет на своё место по дате. Ошибочную отметку
   оттуда же можно удалить.
4. **Смотрите на список** и решайте, до чего руки дошли. Сложность и срочность —
   для вашего удобства; программа ничего за вас не решает.

Выход через пункт 0 сохраняет данные. Пункт 5 сохраняет их в любой момент,
а пункт 6 перечитывает файл с диска (если есть несохранённые изменения,
программа переспросит).
